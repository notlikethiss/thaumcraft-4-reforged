# Thaumcraft 4: Reforged

Unofficial port of **Thaumcraft 4.2.3.5** by Azanor from Minecraft 1.7.10, backported to **Minecraft 1.21.1** on **NeoForge 21.1**.

Mod version **1.1.2** is published on the [1.21.1 release page](https://github.com/notlikethiss/thaumcraft-4-reforged/releases/tag/1.21.1) as `thaumcraft-4-reforged-1.1.2-1.21.1.jar`.

> **Personal use only.** Thaumcraft and all of its assets belong to Azanor. This repository contains the original mod's logic and assets and is not intended for redistribution.

This branch follows `main` (Minecraft 26.3) and contains phases 1–11 of the port. Golems and the Outer Lands are not backported yet. Build instructions and the full description are in the [main branch README](https://github.com/notlikethiss/thaumcraft-4-reforged/blob/main/README.md); branch-specific differences are listed in [BACKPORT.md](BACKPORT.md).
